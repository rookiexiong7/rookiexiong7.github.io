**单位：** SenseNova、AEROBOTICS、Ropedia、Nanyang Technological University、The University of Tokyo

## 1. Motivation：高分是否等于具身智能？

当一个通用多模态模型不再只负责理解指令，而是可以观察机器人相机、读取本体状态、调用控制工具并根据反馈继续行动时，评价它的方式会发生变化。问题不再只是“模型能不能生成合理计划”，而是它能否把计划变成连续的物理结果：抓取是否真的稳定，早先完成的子目标能否保持，失败是否还有恢复路径，推理结束时世界是否仍处于模型刚才看到的状态。

这份 66 页的技术报告以 GPT-6-Astra 为对象，依次回答四个问题：

1. 在允许读取训练集示范、并将交互步数提高到最多 10 倍时，模型在现有具身基准上的能力上界有多高？
2. 把模型接入机器人之后，什么样的动作接口、动作分块和高低层协作方式更有效？
3. 仿真中的高成功率能否迁移到不同形态的真实机器人？
4. 当任务来自人的实际需求、没有同域示范，而且世界在模型思考时继续变化，现有评测还会遗漏什么？

论文给出的判断很克制：GPT-6-Astra **大体跨过了 embodied competence 的门槛，却还没有跨过 practical embodied intelligence 的门槛**。前者表示模型已经能在多种形态和任务上形成有效闭环；后者还要求可靠、及时、成本可控，并能承受真实世界中不可逆的后果。

## 2. Insight：能力上界、系统设计与部署价值是三件事

### 2.1 高成功率同时测量了模型、上下文和预算

论文没有把 GPT-6-Astra 裸模型直接放进所有测试。只要基准提供训练示范，模型就可以先检查这些示范，写出任务说明、动作参考、视觉参考、可执行工具与恢复规则，形成冻结的知识包。测试时，模型再读取这份知识包完成任务。模型权重没有更新，但系统已经获得了任务特定的信息和代码。

扩展预算也改变了能力边界。一次抓取失败后，模型可以重新观察、改变策略并再次尝试；严格的标准步数可能在恢复完成前终止回合。于是，10× 结果回答的是“给模型更多行动机会时最终能完成多少”，而不是“在原基准资源约束下是否已经解决任务”。

因此，接近 100% 的数字需要连同条件一起阅读：它既反映模型推理能力，也反映训练示范覆盖程度、知识包质量、动作接口和允许的恢复次数。

### 2.2 上下文学习更像一次离线编译

论文中的 in-context learning（ICL）不是在每个测试回合中持续学习。每项任务先经历独立的准备阶段，GPT-6-Astra 从训练数据中选择有用信息并写入知识包 $K$；随后 $K$ 被哈希、冻结并以只读方式复制给每个测试回合。测试回合使用全新会话，回合之间不共享经验，也不会把新发现写回 $K$。

[![训练数据先被整理成冻结知识包，再复制给相互隔离的测试回合](/blog/assets/gpt-6-astra-embodied-intelligence/icl-protocol.webp)](/blog/assets/gpt-6-astra-embodied-intelligence/icl-protocol.webp)

*图 2. ICL 准备与测试隔离协议。测试集不会进入准备阶段，测试结果也不会跨回合回写。图源：原论文 Figure 2。*

这种设计把信息泄漏与在线自我改进排除在外，也让“权重冻结”具有明确含义。但知识包大多按任务构建，示范与测试分布越远，收益越弱。它证明模型能把给定经验组织成可执行资源，尚未证明系统能在开放部署中自主积累可迁移经验。

### 2.3 额外交互只有在恢复路径仍然存在时才有价值

扩展预算对 RoboDojo 和 Bench2Dex 帮助很大，却没有让所有任务同步饱和。原因在于，更多步骤只能解决“还来得及纠正”的错误。液体已经洒出、零件已经掉到不可达区域、硬件已经保护停机时，剩余预算不会自动创造恢复路径。

长时程任务还有另一种失败：系统完成了一个子目标，却在后续动作中破坏它。例如耳机已经挂好，之后的一次调整又把它碰落；工具箱已经打开，装入物品时却没有继续保持箱盖。可靠执行需要持续检查已经完成的条件，而不是把子目标标记为完成后永久遗忘。

### 2.4 Harness 不是外围工程，而是被评系统的一部分

同一模型通过不同接口控制机器人，成功率可以相差很大。关节角直接控制把低层运动细节交给多模态模型，表现低于笛卡尔末端目标；固定长动作块减少调用，却可能让新观察进入决策得太晚；VLA 提出的动作如果未经审查直接执行，也不一定比独立 VLA 更好。

这意味着“模型有没有具身智能”无法与 Harness 完全分开讨论。相机能否看到关键接触区域、动作表示是否接近模型的语义推理、高层模型多久检查一次低层动作，都会决定最终行为。

## 3. Method：从 12 个仿真基准到不会暂停的家庭

### 3.1 统一仿真协议

论文覆盖五类共 12 个设置：

| 形态或任务类型 | 基准 |
| --- | --- |
| 桌面机械臂 | RoboDojo、RoboLab、LIBERO-Long++、LIBERO-Ultra-Long、LIBERO-PRO |
| 灵巧手 | Bench2Dex、DexJoCo |
| 人形机器人 | SIMPLE |
| 长时程家庭活动 | BEHAVIOR |
| 视觉语言导航 | VLN-CE R2R、VLN-CE RxR、LHPR-VLN |

只要存在训练集，ICL 准备就可以读取训练示范，但不能读取保留的测试回合或评测器私有信息。知识包通常包含六类内容：任务阶段与约束、动作轨迹和抓取参考、示范图像、正逆运动学与检索工具、完成检查与恢复规则，以及机器人规格和来源记录。

测试时模型权重与知识包保持固定。标准条件使用基准规定的 1× 交互预算；扩展条件沿用同一个回合、历史和环境后果，逐步放宽到累计 10×。成功、终止失败或预算耗尽都会结束回合。BEHAVIOR 的官方预算本来就很长，因此没有运行 10× 条件。

### 3.2 高层推理与低层策略如何协作

Harness 消融在 RoboDojo 的 42 个任务上比较三种 System 1 / System 2 关系：

- 独立 VLA：微调后的 $\pi_{0.5}$ 直接执行动作。
- 开环协作：GPT-6-Astra 给出子目标，VLA 生成并直接执行关节动作序列。
- 闭环协作：VLA 先提出动作，经正运动学转换为末端轨迹；GPT-6-Astra 接受、修改或拒绝后才执行。

论文还改变每次模型调用覆盖的动作数量 $L$。逐动作审查反馈最及时，但 token 很高；一次审查四个候选动作，可以减少调用。直接控制实验则比较绝对末端目标、方向运动命令、关节角，以及固定或自适应动作分块。

### 3.3 真机协议主动撤掉两项仿真假设

真实世界实验使用 8 种机器人配置，涵盖单臂、双臂、灵巧手、轮式移动操作和人形机器人。这里不再提供任务示范或由示范蒸馏的知识包，只给人工整理的结构化先验，例如工具定义、关节限制、相机位置、安全约束和手部开合预设；个别平台还提供可用抓取点等任务级信息。

预算从动作步数改为墙钟时间，通常每次 60 分钟。操作员全程持有急停，成功由人根据物理结果判断。这个条件被论文称为 zero-shot，但它是“无示范、无任务训练”的 zero-shot，不是“没有机器人说明或人工先验”。

### 3.4 下一代评测原型

论文最后提出三条评测原则：

1. 任务应来自人的需求，并按结果效用评价，而不是只检查一个预先写死的终态。
2. 不提供同域训练回合或场景特定示范，机器人需要在部署过程中探索环境与自身形态。
3. 模型推理时世界继续运行，思考时间、动作延迟和其物理后果都进入评分。

作者在 Isaac Sim 中构建一套一居室原型，让 AgiBot G2 只通过机载相机和本体状态完成“做早餐”“收拾桌面”等开放需求。它不是完整的新基准，而是用来暴露现有静态终态评测看不到的失败。

## 4. Experiments：高分成立，但条件与代价不能省略

### 4.1 12 个基准的能力上界

下表列出报告中最能体现差异的结果，公开 SOTA 的统计截止到 2026 年 10 月 12 日。这里的 1× 是单独运行的标准预算实验；10× 是另一条长回合在累计扩展预算终点的结果。两次运行可以走出不同轨迹，因此不能总用简单箭头理解成同一批回合继续执行。

| 基准 | 独立 1× 运行 | 扩展运行最终结果 | 关键条件 |
| --- | ---: | ---: | --- |
| LIBERO-Long++ | 97.5% | 100.0% | ICL，最多 10× |
| LIBERO-PRO | 98.3% | 99.3% | 800 个测试回合；1× 为 786/800，扩展后 794/800 |
| LIBERO-Ultra-Long | 82.2% | 98.9% | 组合长任务，ICL 覆盖较强 |
| RoboDojo | 54.2% | 81.9% | 1× 数字带 VLA；10× 长回合在自身 1× 截点仅为 27.6% |
| DexJoCo | 78.2% | 87.3% | 灵巧手，最多 10× |
| Bench2Dex | 25.6% | 61.5% | 额外交互收益显著 |
| BEHAVIOR | 37.0% | 未运行 | 100 个任务、每项 1 个回合，官方预算已较长 |
| LHPR-VLN | 21.1% | 28.9% | 长时程导航仍是最低结果 |

SIMPLE 的标准预算 ICL 结果也需要按可比子集阅读。在四个共同任务的 120 个回合上，zero-shot 为 70.8%，ICL 为 90.8%；$\Psi_0$ 的公开参考为 90.0%，只差一个成功回合，不能据此断言统计上更优。对两种设置都成功的 81 个回合，ICL 将平均动作步数从 376.9 降到 210.4，但平均测试 token 从 2.64M 增至 6.40M；每项任务还需要一次性的 8.34M token、90.4 分钟准备。

### 4.2 时间与 token 是能力上界的组成条件

强结果并不便宜。报告估计其运行中约 98% token 为缓存输入，并用“1M token 约 1 美元”作粗略换算；这只是作者的经验规则，不是通用定价结论。

即使 LIBERO-Long++ 在 1× 已超过 97%，每回合仍约消耗 1M token，并需要接近一小时的推理与工具时间；LIBERO-Ultra-Long 约为 9M token、接近两小时。RoboDojo 的扩展预算回合平均超过三小时。动作预算不计算推理延迟，仿真又会在推理时暂停，所以这些数字既没有惩罚模型“让世界等待”，也不能代表真实机器人的吞吐量。

### 4.3 闭环协作有效，但最高结果也是最贵结果

| RoboDojo Harness | 平均成功率 | 平均 token / 回合 |
| --- | ---: | ---: |
| Agentic GPT-6-Astra baseline | 15.56% | 2.560M |
| VLA 独立执行 | 6.91% | 未报告 GPT token |
| VLA 开环 | 5.83% | 0.387M |
| VLA 闭环，逐动作审查 | 23.61% | 7.664M |
| VLA 闭环，$L=4$ | 25.83% | 2.796M |
| ICL | 29.67% | 9.567M |
| ICL + VLA 闭环 | 54.17% | 19.335M |

一次审查四个 VLA 动作相较逐动作审查，token 下降 63.5%，成功率反而从 23.61% 升至 25.83%。这说明更高的审查频率不必然更好：过短的动作块会增加上下文和调用负担，也可能让高层模型过度干预低层连续运动。

动作接口的结果同样明显。关节角控制只有 9.72%，低于末端目标 baseline 的 15.56%；方向运动命令达到 18.06%，自适应动作块达到 20.00%，且 token 分别为 1.908M 和 1.146M。模型更适合表达“末端向哪里移动、完成什么接触”，精确关节控制仍应尽量交给低层控制器。

### 4.4 真机展示了跨形态能力，也暴露出接触与时间瓶颈

同一个 GPT-6-Astra 在 8 种真机配置上完成了堆叠、折叠、双臂协作、房间级导航和人形行走等任务。作者把结果按任务属性总结得比“平均成功率”更有信息量：

| 真机能力 | 报告结果 | 应如何理解 |
| --- | ---: | --- |
| 刚性抓取放置 | 17/18 | 当前最稳定的一类，但任务与平台并不完全相同 |
| 三个平台的插头插入 | 0/11 | 精密接触仍未解决 |
| AgileX Tracer 导航与搜索 | 9/23 | 房间级长时程任务明显更难 |
| 双臂 Piper 报告回合 | 14/14 | 展示零样本双臂协调；部分任务仅 1–2 次，不能估计稳定成功率 |
| Unitree G1 抓取放置 | 2/3 | 高层慢推理通过现有低层控制接口驱动人形机器人 |
| Unitree G1 转向、接近、停止 | 3/3 | 与操作任务分开评测 |

[![GPT-6-Astra 在八种真实机器人配置上的代表性成功轨迹](/blog/assets/gpt-6-astra-embodied-intelligence/real-robots.webp)](/blog/assets/gpt-6-astra-embodied-intelligence/real-robots.webp)

*图 5. 从单臂到人形机器人的代表性真机轨迹。图中次数是各任务的计数结果，不代表统一难度下的大样本比较。图源：原论文 Figure 8。*

真机还展示了一种值得重视的主动视觉行为。单臂插花时，腕部相机看不到花瓶口，任务失败；双臂系统让空闲手臂移动相机，直到花瓶口进入视野，再完成插入。这里相机视角本身成为动作空间的一部分，而不只是固定传感器。

但“多试几次”在真机上会产生累积后果：碰撞触发保护停机，物体掉落可能不可逆，手指关节在反复抓取中升温到 62°C，移动操作平台也因躯干过热终止任务。在 G1 上，GPT-6-Astra 约 90% 的运行时间用于思考，一次操作超过一小时。仿真中用时间换成功率的策略，到了真实世界会同时增加安全、硬件与人工监督成本。

### 4.5 当世界不暂停，正确决定也可能变成错误动作

家庭原型把推理时间计入世界时间后，出现了静态终态指标不容易捕捉的失败：机器人收拾书本时碰落桌面物体并推歪显示器；冰箱门从 300 秒一直开到 765 秒；水龙头没有关闭，34 秒时水已溢到地面；鸡蛋已经凝固后，系统直到约 90 秒后才关火，余热继续将鸡蛋烧焦。

[![家庭原型中碰撞、遗忘冰箱门、无法进入冰箱、溢水和烧焦鸡蛋的失败序列](/blog/assets/gpt-6-astra-embodied-intelligence/household-failures.webp)](/blog/assets/gpt-6-astra-embodied-intelligence/household-failures.webp)

*图 6. 世界在推理时继续运行后暴露的五类失败。外部视角仅用于展示，模型只接收机载相机。图源：原论文 Figure 12。*

这些案例支持下一代评测的方向，却仍是少量定性样例。原型的物理真实性、隐藏评测器能否可靠判断接触与烧焦、不同硬件延迟如何公平比较，都没有被完全解决。作者也指出，视觉语言成功检测器在接触密集装配上的可靠性仍不足，长时程家庭仿真能否预测真机表现也缺乏证据。

### 4.6 结论边界

这份报告最强的证据，是同一通用模型在多类仿真、不同动作接口和多种真机形态上表现出闭环纠错能力；最弱的地方，是这些条件尚未形成统一、成本受控的比较：

- 公开基线来自各论文报告，并非在相同硬件、延迟、感知接口和总成本下重跑。
- 1× 与 10× 是不同运行；论文还报告 10× 长回合内部的 1× 截点，两者可能明显不同。
- ICL 使用任务训练示范，知识包大多不能跨任务直接迁移。
- 真机任务重复次数通常很少，变形物体的“成功”在各平台上也没有统一质量阈值。
- 多数仿真在模型推理时暂停，因此成功率没有包含延迟造成的物理风险。
- 家庭原型证明了评价盲点的存在，还没有证明所提评分体系已经足够可靠。

所以，论文标题中的问题不能靠一个总分回答。现有证据表明 GPT-6-Astra 已经是能够跨任务、跨形态组织动作的具身智能组件；它还不是可以低成本、长期自主、对失败后果负责的完整机器人系统。

## 5. Conclusion

这篇报告真正改变的不是“谁在某个排行榜上领先”，而是具身系统应该怎样被拆解和评价。模型能力、任务特定上下文、动作接口、低层控制、反馈频率和交互预算共同决定结果；只报告模型名称与成功率，已经不足以描述系统。

从研究角度看，接下来的重点也很清楚。第一，知识包需要从任务内记忆走向跨任务、跨形态的经验迁移。第二，验证机制要能判断真实的接触、支撑和任务条件，而不只依赖画面看起来合理。第三，恢复策略必须识别不可逆后果，并在动作前评估风险。第四，长时程系统要持续维护已经建立的条件，避免后续动作破坏早先进展。第五，评测必须把墙钟时间、推理延迟、安全停机和人工监督纳入成本。

如果把“具身智能”理解为模型能否在感知与动作之间形成有效闭环，那么 GPT-6-Astra 的确跨过了一个重要门槛；如果它意味着机器人能在持续变化的世界里及时、可靠、经济地满足人的需求，这份报告本身给出的答案仍然是否定的。
